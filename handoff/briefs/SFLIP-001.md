# 简报 SFLIP-001：故宫外朝三大殿 · 沉浸式单页网页

## 任务

用户原话：「启动 s flip m loop 制作一个极其酷炫精美的介绍故宫太和殿、中和殿、保和殿这三大殿的一个网页，有各种炫酷的动画、艺术的表达。」

我的理解：做一个**单页静态网页**，用沉浸式、叙事滚动的方式介绍故宫外朝三大殿（太和殿 / 中和殿 / 保和殿）。
「极其酷炫精美」= 视觉冲击力顶级 + 动画编排有设计意图 + 有艺术表达（不只是图文卡片）；
「有各种炫酷的动画」= 多套动效体系、彼此分工、不是同一个效果复制三遍。
**这是文化殿堂级展示页，不是信息列表页。** 三殿各有各的气质：太和殿（最高等级 · 巨构 · 威严）、
中和殿（最小 · 攒尖 · 精巧 · 中庸）、保和殿（明代原形 · 殿试 · 文脉），三段不能雷同。

## 验收（可判定，每条都能被一条命令或一个明确步骤判定）

- **A1** `npm ci && npm run build` 退出码 0；产出 `dist/index.html`，双击/本地静态服务器可正常打开。
- **A2** 生产构建下真实浏览器打开：console error = 0、pageerror = 0、**外部网络请求 = 0**（所有资源本地化，含字体）。
- **A3** 375px 与 1440px 视口**均无横向滚动条**；375px 下可点区域 ≥ 44×44px；文字放大 200% 不重叠不丢内容。
- **A4** 键盘可完成全部核心操作：Tab 顺序与视觉顺序一致、焦点环清晰可见（≥2px 或 2px offset）、Esc 可关闭浮层。
- **A5** `prefers-reduced-motion: reduce` 下非必要动画全部停用，页面信息**完整可读**（内容不能因关动画而消失）。
- **A6** 正文与背景对比度 **≥ 4.5:1**、大字 **≥ 3:1**、控件边框/图标 vs 相邻背景 **≥ 3:1**（用脚本量，不靠肉眼）。
- **A7** 滚动动画 60 帧采样：`frameId` 互不相同、时间戳严格递增（不重复帧、不掉帧成幻灯片）。
- **A8** CLS ≤ 0.1；首屏可交互 ≤ 2.5s（本地实测）。
- **A9** `npm test` 退出码 0；测试条数**从 stdout 解析**，不手抄。
- **A10** 页面覆盖三殿各自的：形制 / 尺寸 / 用途 / 匾额对联 / 沿革（内容在下面「素材」里有全部硬数字）。
- **A11** 三殿视觉**可区分**：每殿有自己的构图母题与动效节奏；同类元素（按钮/卡片/标题）风格统一。

## 素材（已核实的事实底稿 · 数字可直接用）

**总纲** — 故宫（紫禁城）：明清 24 帝皇宫，始建明永乐四年（1406）、永乐十八年（1420）落成；
占地 72 万 m²，建筑面积约 15 万 m²，宫殿七十多座，房屋九千余间；
**世界现存规模最大、最完整的宫殿型建筑**；1987 年列入《世界文化遗产》，
2024-07-27 又作为世界遗产「北京中轴线——中国理想都城秩序的杰作」的一部分入选。
南北长 961 m、东西宽 753 m，城墙高 10 m，护城河宽 59 m；四门：午门（南）、神武门（北）、东华门（东）、西华门（西）。
**外朝**中心即三大殿，是国家举行大典礼的地方，两翼为文华殿、武英殿；内廷中心为后三宫（乾清宫、交泰殿、坤宁宫）。
三大殿位于紫禁城南北中轴线（即北京中轴线）上，**同坐一座三层汉白玉台基（须弥座），台基高 8.13 m**；
台基四周环汉白玉栏杆，栏杆下设排水石雕龙头，下雨时一起喷水，形成**「千龙吐水」**景观。
共同视觉母题：**黄琉璃瓦顶 + 朱红立柱 + 汉白玉台基栏板 + 沥粉贴金与和玺彩画**。

**沿革（三殿同步）** — 1420 同时建成，初名奉天殿 / 华盖殿 / 谨身殿 → 1562 改名皇极殿 / 中极殿 / 建极殿 →
1645 定名今。太和殿屡遭雷火（1421 雷击、1557 火、1597 火、1679 火），**现存形制为 1695–1697 康熙重建**；
**保和殿是少数至今保留明代原形的建筑之一**（主体梁架仍为明代）；**中和殿天花内构件上仍留有明代「中极殿」墨迹**。

**太和殿** — 三大殿最南面；紫禁城规模最大、开间最多、进深最大、屋顶最高的殿宇，
**中国现存古建筑中面积最大的一座**，明清北京城最高建筑，号「中华第一殿」。
面阔 11 间（63.96 m）、进深 5 间（37 m），**建筑面积 2377 m²**，殿高 26.92 m，**通高 35.05 m**。
**重檐庑殿顶**：正脊螭吻各由 13 块琉璃构件组成，高 3.40 m、宽 2.68 m、厚 0.32 m、**重约 4.3 t**，紫禁城最大；
垂脊檐角琉璃神兽 = 骑凤仙人 + **10 只**（龙、凤、狮子、天马、海马、狻猊、狎鱼、獬豸、斗牛、行什），
**数量为现存古建筑中所仅见**。檐下密集斗栱，室内外梁枋和玺彩画，门窗上部菱花格、下部浮雕云龙。
**立柱 72 根**，最高 12.7 m、最粗直径 1.06 m（原楠木，毁于 1679 火灾，今为康熙间松木拼接）；
宝座两侧 **6 根沥粉贴金云龙巨柱**为紫禁城独有，**柱上龙头全都望向宝座**。
地面铺**金砖 4718 块**（每块边长约 0.67 m）。
宝座：髹金漆云龙纹宝座，**明嘉靖年间遗物**，通高 172.5 cm、座高 49 cm、座宽 158.5 cm、脚踏高 30 cm，
圈椅式金丝楠木，**雕 13 条金龙**；下承高约 2 m 的朱漆方台、镶大量宝石、正面与左右 7 级台阶；后为七扇雕龙金漆屏风（清制）。
藻井正中蟠卧巨龙，龙头下探口衔大铜珠「**轩辕镜**」+ 6 颗小珠。
殿外「丹陛」（月台）陈设：日晷、嘉量各一，铜龟铜鹤各一对，**铜鼎 18 座**（乾隆年间铸）。
匾额「**建极绥猷**」；对联「帝命式于九围兹惟艰哉奈何弗敬，天心佑夫一德永言保之遹求厥宁。」
用途：**即位、大婚、册立皇后、命将出征**等大典；**万寿节 / 元旦 / 冬至**「大朝仪」、朔望「常朝仪」；清初曾在此殿试（传胪仍在太和殿）。

**中和殿** — 位于太和殿与保和殿之间，**面积最小**。1420 建成，初名华盖殿 → 中极殿 → 1645 改今名。
「中和」取自《礼记·中庸》「中也者，天下之本也；和也者，天下之道也」。
**平面正方形，高 29 m，单檐四角攒尖顶**，覆黄琉璃瓦，中置**铜胎鎏金宝顶**；面阔 3 间、进深 3 间、四面出廊，金砖铺地，
**建筑面积 580 m²**。四面开门：南面三交六椀槅扇门 12 扇、东西北各 4 扇；石阶南北各三出、东西各一出，
中间浮雕云龙纹御路；**门窗形制取自《大戴礼记》「明堂」，刻意不与另两殿雷同**；
内外檐饰金龙和玺彩画，天花沥粉贴金正面龙；殿内正中宝座，两旁两个**肩舆**（皇帝宫内所乘之轿）。
匾额「**允执厥中**」（《尚书·大禹谟》「人心惟危，道心惟微，惟精惟一，允执厥中」）；
对联「时乘六龙以御天所其无逸，用敷五福而锡极彰厥有常。」
用途：大典前**小憩**并受朝拜；**亲祭**（天坛/地坛/社稷坛/太庙/先农坛）前一日阅视祝版；
祭先农坛暨亲耕前一日**查验种子与农具**；皇太后上徽号时阅奏书；
清朝**每七年纂修玉牒**（皇家家谱）告成恭进御览并举行存礼；有时召见官员或赐食。

**保和殿** — 位于中和殿以北。1420 建成，初名谨身殿 → 1562 建极殿 → 1645 改今名。
「保和」出自《易经》「志不外驰，恬神守志」。
面阔 9 间、进深 5 间，**高 29.50 m，建筑面积 1240 m²**。**重檐歇山顶**，覆黄琉璃瓦，**上下檐角各 9 只小兽**；
上檐单翘重昂七踩斗栱、下檐重昂五踩斗栱；内外檐金龙和玺彩画，天花沥粉贴金正面龙。
采用「**减柱造**」法式：**减去殿内前檐六根金柱**，空间开阔；金砖铺地，坐北向南雕镂金漆宝座，东西两梢间为暖阁。
后阶陛中间有**云龙石雕（流云立龙）**，雕云、龙、海水、山崖；石料产自京西房山大石窝，一万余工人拖运近一个月。
匾额「**皇建有极**」（任君建立天下最高准则）；
对联「祖训昭垂我后嗣子孙尚克钦承有永，天心降鉴惟万方臣庶当思容保无疆。」
用途：明为大典前更衣；清**每年除夕、正月十五赐宴**外藩王公及一二品大臣；每岁终宗人府、吏部在此填**黄册**；
顺治三年—十三年顺治帝居此（时称**位育宫**）、顺治帝大婚在此；康熙帝至康熙八年居此（时称**清宁宫**）；
**乾隆五十四年（1789）起成为每科殿试的固定场所**（会试中式者为贡士方可应试，题目由皇帝拟定、指定大臣阅卷）。
曾设「保和殿大学士」一职（顺治至乾隆，三殿三阁大学士之一，鄂尔泰、张廷玉等曾获此衔）。
